## What to Build

### 1. Root docker-compose.yml

Create /workspace/projects/sanad_agent/docker-compose.integration.yml that brings up:

- orchestrator (port 8100) — from orchestrator/Dockerfile
- hr_agent (port 8200) — from hr_agent/Dockerfile
- sanad_agent (port 9000) — from existing Dockerfile
- reasoning_layer (port 5600) — from /workspace/projects/SanadReasoningLayer if Dockerfile exists, else skip

Network: all on a shared Docker bridge network called `sanad_net`

Environment variables (pass through from .env):
- ORCHESTRATOR_URL=http://orchestrator:8100
- AGENTS_API_KEY (from .env or generate a test key)
- HR_AGENT_URL=http://hr_agent:8200

If SanadReasoningLayer has no Dockerfile, create a stub: a single-file FastAPI app
at /workspace/projects/sanad_agent/reasoning_stub/main.py that:
- Exposes POST /api/v1/reasoning/generate
- Returns {"result": "STUB: " + prompt} — no real LLM call needed for the integration test
- Runs on port 5600

### 2. Integration Test Script

Create /workspace/projects/sanad_agent/tests/test_integration.py

The test must:
1. Submit a task to Orchestrator: POST /tasks with a 2-step workflow
   - Step 1: role=sanad_agent, prompt="Echo: Hello from integration test"
   - Step 2: role=sanad_agent, prompt="Confirm receipt of: {step_1_result}"
2. Poll GET /tasks/{task_id} every 2 seconds for up to 60 seconds
3. Assert final status = DONE
4. Assert step_1 result is non-empty
5. Assert step_2 result references step_1 result

This test MUST be runnable without live Docker (mock the HTTP calls using httpx TestClient
or unittest.mock). If a live integration run is possible (services are up), also attempt it
and record the result — but do not FAIL the test suite if services aren't running.
